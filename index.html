How to Install

1
Download & Unzip
Unzip the downloaded file and drag MouseLocator.app into your Applications folder.
2
First-Time Launch
Right-click MouseLocator.app → Click Open → Click Open again in the security prompt.
Note: This is only required once. macOS requires this for untrusted developers.
3
Set Your Hotkey
Open macOS Shortcuts app → Create new shortcut → Add 'Open App' action → Select MouseLocator → Assign hotkey to Cmd + Control + M.
