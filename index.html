How to Install & Setup

1
Unzip
Extract the downloaded MouseLocator.zip file and drag MouseLocator.app into your Applications folder.
2
Bypass Gatekeeper
Double-click the app. If macOS says "Apple could not verify...", click Done. Then go to System Settings → Privacy & Security, scroll down to the security section, and click Open Anyway.
3
Grant Permissions
In System Settings, go to Privacy & Security and add MouseLocator to BOTH lists:

• Accessibility (needed to move the mouse)
• Input Monitoring (needed for the hotkey)
