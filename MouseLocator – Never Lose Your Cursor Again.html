How to Install

1
Install
Unzip the downloaded file and drag MouseLocator.app into your Applications folder.
2
Open Once
Right-click the app and select 'Open' to bypass the Mac security prompt (you only do this once).
3
Set Hotkey
Open the built-in macOS 'Shortcuts' app, create a new shortcut with the 'Open App' action targeting MouseLocator, and assign it to Cmd + Control + M.
